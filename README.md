# Software Defined Networking Lab

An SDN lab built using OpenFlow, OpenDaylight, Mininet and Python. Used to simulate Traffic and Attacks on a network with monitoring tools. 

## Overview

This Project is a simulated Software Defined Lab setup to simulate traffic pattern and network topology to help develop increasingly advanced Firewall and traffic orcestration.

This lab exists to solve a problem in simulating traffic and learn how to defend against malisous traffic. Equip with monitoring tools to analyse traffic and help develop more effective firewalls.

## Features

- Modular Segments for Topology, Monitoring, Attacks, and controller settings.
- Configuration features to piece meal each part together.

## Repository Structure

- Attacks: To Store attack scripts
- Automation: To Store automation logic
- Controller: To Store Controller flow setups
- Docs: To Store in-depth documentation
- experiments: Preloaded configurations
- Monitoring: Monitoring and statisical scripts
- Results: To Store Saved results of the experiments
- Topology: Scripts to set up the network topology
- Config.py and config.ymal: used to set variablies needed for the environment to function
